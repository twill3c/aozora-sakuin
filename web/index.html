この索引について

青空索引 — 青空文庫の 5,000 作品を単一の全文索引に統合し、語がどう使われているかを 前後文脈つきの用例集として引く。収録は青空文庫のアクセスランキング順に、1 著者 16 作を上限として 決定論的に選定（著者 921 名を全員収録）。本文は配信していない — 前後文脈は索引そのものから復元している。

青空文庫 ・ 本文は著作権保護期間の満了した作品のみ ・ 索引の構築と照合は Rust / WebAssembly
