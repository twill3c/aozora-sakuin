# 青空索引（aozora-sakuin）

青空文庫の **5,000 作品**を単一の全文索引に統合し、任意の語句が**どの作品でどう使われているか**を
前後文脈つきの用例集（KWIC）として引く。フリートの各アトラスが「一作・一作家の中を掘る」道具で
あるのに対し、本プロジェクトは「作家と時代をまたいで語を横に読む」道具である。

```
「吾輩」 1,146 件
  …。／自分は漱石の「【吾輩】は猫である」という本…      太宰治『人間失格』
  …有の契約で出版した『【吾輩】は猫である』を、曩に…    夏目漱石『それから』
```

## なぜ Rust か

速度のためではない。正味 302.9 MB の本文に対する素の接尾辞配列は 4 バイト整数 × n = **1.2 GB** に
なり、ブラウザへ配信できない。配信できる大きさに収めるには BWT と疎な標本による圧縮索引が要り、
その構築（SA-IS）と照合（rank/select のビット演算）は JavaScript では現実的に書けない。

**索引が本文を兼ねる。** 原文は配信していない。前後文脈は索引そのものから LF 写像を辿って復元する。

**索引も丸ごとは配らない。** 件数は HTTP Range で必要なバイトだけ読む。各シャードの先頭にある
目次（作品表・木の形・rank 標本・C 表）を初回に落としておき、後方探索で足りないワードだけを
取りに行く。1 クエリの追加転送は 0.08〜0.14 MB で、5,000 作すべてを正確に数えられる。
用例を出す段になってはじめて、件のあるシャードを丸ごと（最大 4.7 MB）取りに行く。

| | 実測 |
|---|--:|
| 収録 | 5,000 作 / 著者 921 名 |
| 正味本文 | 302.9 MB（102,352,565 字） |
| 索引 | 232.9 MB（本文の 0.769 倍・平均符号長 4.82 ビット/バイト） |
| シャード | 53 枚 / 最大 4.7 MB |
| 初回に落とす資材 | 0.28 MB（wasm 78 KB + 作品台帳 188 KB） |
| 索引の目次（初回のみ） | 11.9 MB |
| **1 クエリの追加転送** | **0.08〜0.14 MB**（索引全体の 19 分の 1） |
| 照合器 | 42,956 バイト（wasm32・外部クレートゼロ） |

## 収録の選び方

順序に**青空文庫自身のアクセスランキング**（2009-01 以降の月次 164 本・各 500 件）を使い、
1 著者 16 作を上限として決定論的に選ぶ。私の趣味は入らず、再実行しても 1 バイト変わらない。

当初は作品 ID 昇順で選んでいたが、**作品 ID は登録順であって重要度ではない**。代表作 21 点のうち
採録は 11 点で、芥川竜之介は羅生門も蜘蛛の糸も入らなかった。決定論は再現性を保証するだけで
代表性は保証しない。差し替え後は代表作 **21/21**、ランキング上位 100 位は全て採録。

## 表記ゆれ

収録の **39% が旧仮名**なので、「あわれ」で引いて「あはれ」が出ないのでは成立しない。

歴史的仮名遣いへの変換は本来、語の切れ目の知識を要する。それを辞書で与えると辞書が「正しさ」の
根拠になって検証が循環するので、ここでは**機械的な置換だけ**を行い、規則の妥当性は台帳の
**文字遣い種別**（青空文庫が各作品に付けている独立した外部ラベル）で較正する。

| 規則 | 旧仮名の作品に落ちる割合 | 既定 |
|---|--:|:--|
| い→ゐ / う→ふ / 長音 よう→やう | 96〜99% | 有効 |
| わ→は / ず→づ / お→ほ | 77〜84% | 有効 |
| お→を / え→へ / か→くわ | 5〜37% | **無効**（「をもう」が「…を、もう…」に当たる） |

下 3 つは**規則としては正しい**が語の切れ目を知らない部分文字列照合では区別できない。
既定では外し、形ごとに件数を見せて利用者が選べるようにしている。隠さずに出す。

## 使い方

```bash
# 1. 収録を選ぶ(ネットワーク不要・手元の台帳から決定論的に)
python pipeline/select5000.py

# 2. 本文を取得(約 70 分・0.8 秒間隔・レジューム可)
python pipeline/fetch_bronze.py

# 3. 正規化(15 秒)
python pipeline/normalize.py

# 4. 索引を組む(27 秒)
cargo run --release --manifest-path rust/Cargo.toml --bin build_shards -- 1_500_000
python scripts/build_web_meta.py

# 5. 手元で見る
python scripts/serve.py        # http://127.0.0.1:8787/

# 品質ゲート(Python / fmt / clippy / cargo test / wasm / 実地検査)
python scripts/verify.py
```

## 構成

```
pipeline/     取得・選定・正規化(Python。出荷物ではない)
rust/src/     sais bwt bitvec wavelet fm shard variants wasm
web/          素の HTML/CSS/JS。索引の構造は知らない(N-02)
scripts/      品質ゲートと較正
tests/        選定 14 / 正規化 13 / 表記ゆれ 6 / 画面 8
```

**オラクル** — すべての索引操作に総当たりの参照実装を置き、両者の一致を検査する。
FM-index の探索が総当たり検索と全ヒット位置で一致すること、索引から復元した本文が原文と
バイト単位で一致すること、シャード合計が全文の総当たりと一致すること。
圧縮索引が自己無矛盾であることは、解釈が正しいことを意味しない。
